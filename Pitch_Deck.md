## 🔥 Key Features & Capabilities

### 2. Premium Casino & Economy System
Built on a blazing-fast PostgreSQL database, the economy system is fluid and highly addictive.
* **Multiplayer Roulette (`+roulette`):** Opens a public table in the chat where multiple members can place chips on Red, Black, Green, or specific numbers simultaneously before the wheel spins.
* **Coinflip (`+cf`):** Instant animated coinflips with embedded spinning GIFs that edit directly into the win/loss result.
* **Anti-Spam Locks:** We engineered a strict "1-Game-Per-Channel" lock. If a Roulette table is spinning, nobody can spam a Mafia lobby over it, ensuring your chat never gets flooded.

### 3. Multiplayer Mini-Game Lobbies

* **Crash:** A high-stakes multiplier rocket crash game.
